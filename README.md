# Decision Tree & Naive Bayes Classification

## Overview

This project implements and compares two popular machine learning classification algorithms:

- Decision Tree
- Naive Bayes

The project contains three parts:

1. Building and visualizing a Decision Tree using the PlayTennis dataset.
2. Comparing Decision Tree and Naive Bayes using confusion matrices.
3. Applying Decision Tree to the Titanic dataset and evaluating its performance.

---

## Features

- Decision Tree classification
- Naive Bayes classification
- Data preprocessing and encoding
- Decision Tree visualization
- Confusion Matrix visualization
- Classification Report
- Accuracy evaluation
- Titanic dataset classification

## How to Run

### Part A

Build and visualize the Decision Tree.

```bash
python part_a.py
```

Outputs:

- Decision Tree visualization
- Classification Report
- Accuracy
- Confusion Matrix

---

### Part B

Compare Decision Tree and Naive Bayes.

```bash
python part_b.py
```

Outputs:

- Accuracy comparison
- Classification Reports
- Confusion Matrix comparison

---

### Part C

Apply Decision Tree to the Titanic dataset.

```bash
python part_c.py
```

Outputs:

- Model Accuracy
- Classification Report
- Titanic Confusion Matrix
